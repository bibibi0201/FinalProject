# Project Structure Description

## ESP32 โฟลเดอร์นี้ใช้สำหรับเก็บ โค้ดของบอร์ด ESP32 ที่ใช้ในโปรเจค ภายในจะประกอบด้วยโค้ดสำหรับ:
  - การอ่านค่าจากเซนเซอร์จาก MPU6050 และ Active Buzzer
  - การประมวลผลท่าทางว่านั่งถูกหรือผิดและแยกท่านั่งที่ผิดว่าผิดจากอะไร (posture detection)
  - การเชื่อมต่อ WiFi และส่งข้อมูลไปยัง Firebase

## Report โฟลเดอร์นี้เก็บ เอกสารรายงานของโปรเจค (CDIO) ได้แก่:
  - รายงาน CDIO
  - Flowchart การทำงานของระบบ
  - รูปภาพอุปกรณ์ที่ใช้
  - เอกสารอ้างอิง (References)

## data_user โฟลเดอร์นี้ใช้เก็บ ข้อมูลจากการทดลองกับผู้ใช้งาน (User Study) ได้แก่:
  - User_Result
      ผลการประเมินจากแบบสอบถาม 
  - Pre-Post Test
      แบบทดสอบก่อนและหลังการใช้งาน เพื่อวัดความแตกต่างของความรู้หรือพฤติกรรมโดยนำข้อมูลที่ได้มาวิเคราะห์ด้วยสถิติ Paired t-test เพื่อพิจารณาว่าการเปลี่ยนแปลงที่เกิดขึ้นมีนัยสำคัญทางสถิติหรือไม่
    
## guidedev โฟลเดอร์นี้เก็บ เอกสารอธิบายขั้นตอนการพัฒนาโปรเจค เช่น:
  - วิธีติดตั้งระบบ
  - วิธีใช้งาน

## posture โฟลเดอร์นี้เก็บ โค้ดของแอปพลิเคชัน (Flutter Application) ภายในประกอบด้วย:
  - UI ของแอป
  - การเชื่อมต่อ Firebase
  - การแสดงผลข้อมูลท่าทาง
  - ระบบแจ้งเตือนผู้ใช้งาน
